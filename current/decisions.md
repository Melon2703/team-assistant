# Decision Log — `<TEAM>`

> Накопительный список значимых решений. Сюда переносятся решения из `current/focus.md`, когда они становятся «decided».
>
> Не каждое решение нужно сюда писать. Только те, к которым потом возможно вернуться:
> почему так решили? кто принял? что было альтернативой? какие предпосылки изменились бы для пересмотра?

## Формат записи

```
### YYYY-MM-DD — Краткое название решения

- **Decision:** что именно решено
- **Owner:** кто принял (или collective)
- **Context:** на основании чего решали (ссылки на Slack-thread, Asana, Coda, встречу)
- **Alternatives considered:** какие варианты обсуждались
- **Tradeoffs:** что выиграли, чем пожертвовали
- **Revisit when:** при каких условиях стоит пересмотреть
- **Tags:** version / feature / process / staffing / scope
```
